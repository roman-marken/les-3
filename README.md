# Панель керування завданнями

Невелике домашнє завдання на React + TypeScript. Оформлення — Tailwind CSS.

## Запуск

```bash
npm install
npm run dev
```

Перевірка типів і збірка: `npm run build`.

## Структура

- `src/types/Task.ts` — тип завдання.
- `src/App.tsx` — стан завдань, додавання, вибір і зміна статусу.
- `src/components/TaskForm.tsx` — контрольована форма та фокус через useRef.
- `src/components/TaskList.tsx` — список із вибором завдання.
- `src/components/TaskDetails.tsx` — деталі та позначка виконання.

Назва обов’язкова: порожній рядок або лише пробіли не приймаються.
Після додавання форма очищується, фокус повертається в поле назви, а нове завдання відкривається в деталях.
Масив завдань зберігається в батьківському компоненті й оновлюється імутабельно через updater function.
Після перезавантаження сторінки відновлюються початкові завдання.
